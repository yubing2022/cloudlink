# Phase 0: 准备工作

> 预计耗时：0.5 天  
> 目标：把所有需要的凭证和资料收集齐全

## 📋 资料清单

把以下信息收集后告诉 Codex（粘贴或截图都行）：

### 1. 服务器信息

| 项 | 说明 | 获取方式 |
|---|---|---|
| 服务器公网 IP | 例如 `47.98.123.45` | 阿里云 ECS 控制台 |
| SSH 登录方式 | 密码 or 密钥 | 控制台「实例」→「重置密码」/「密钥对」 |
| root 密码 | 若密码登录 | 重置后复制 |
| .pem 密钥路径 | 若密钥登录 | 下载到本地 |

### 2. 域名

| 项 | 说明 | 备注 |
|---|---|---|
| 域名 | 例如 `cloud.example.com` | 必须有，可注册商任意 |
| A 记录解析 | 是否已解析到服务器 IP | 未解析需先配置 |

**推荐**：用阿里云域名（解析快、备案流程顺）；用 Cloudflare 代理也行。

### 3. Home Assistant 信息

| 项 | 说明 | 获取方式 |
|---|---|---|
| HA 访问地址 | `http://192.168.x.x:8123` 或公网域名 | HA 网页 |
| HA 版本 | 例：`2024.12.0` | HA 网页左下角 |
| Long-Lived Token | 永久访问令牌 | 见下方获取步骤 |

**获取 Long-Lived Token 步骤**：

```
1. 浏览器打开 HA
2. 左下角点你的用户名（个人资料）
3. 滚到页面最下方「长期访问令牌」
4. 点「创建令牌」
5. 名字填：cloudlink
6. 复制生成的字符串（只显示一次！）
```

### 4. 设备清单

至少准备 5-10 个常用设备的 `entity_id`，获取方式：

```
HA → 开发者工具 → 状态 → 搜索常用设备
```

示例：
```
light.living_room_main     （客厅主灯）
light.bedroom_ceiling      （卧室吸顶灯）
switch.kitchen_outlet      （厨房插座）
sensor.living_room_temp    （客厅温度）
climate.bedroom_ac         （卧室空调）
```

### 5. 注册邮箱

用于云端账号注册，建议用：
- 不常用的邮箱（避免垃圾邮件）
- 开启 2FA（生产环境推荐）

## 🔒 安全检查清单

在开始之前，请确认：

- [ ] 服务器 SSH 端口已变更（不用默认 22 最稳，可改 2222 等）
- [ ] 服务器已开启基础安全组规则（暂可全开，后续 Phase 1 收紧）
- [ ] HA 已开启 HTTPS（生产环境必须）
- [ ] 域名 WHOIS 信息已隐藏
- [ ] 你有一个安全的密码管理器（存这些 token）

## 💬 怎么告诉 Codex

直接贴到对话里，格式随意，例：

```
1. 服务器 IP：47.98.123.45
2. SSH：密码登录 root 密码 XXXX
3. 域名：cloud.example.com（已解析）
4. HA：http://192.168.1.100:8123
   HA 版本：2024.12.0
   Token：eyJ0eXAiOiJKV1Q...
5. 设备：light.living_main, switch.kitchen_outlet, ...
6. 邮箱：me@example.com
```

## ✅ Phase 0 完成标志

你能把上述 5 项内容一次性贴到对话里，**Phase 0 完成**，进入 Phase 1。
